Backup & recovery

Export a JSON backup regularly and keep it securely. Import restores data in this browser only.

Backup files may contain full CNIC values. Keep them in an access-controlled location; do not upload them to this public GitHub repository.

Bluetooth thermal printer

This attempts Web Bluetooth Low Energy (BLE) printers with a writable GATT characteristic. Many budget thermal printers use Bluetooth Classic/SPP and cannot be directly controlled by a web page; use the Android print dialog/native print app for those models.

Printer not connected.

For a real Bluetooth printer, exact support depends on the printer model and its BLE/ESC-POS protocol. If connection fails, send the printer model name/photo so the correct method can be chosen. Browser print is the fallback.

Login settings

Login credentials are stored only in this browser. This is not a production authentication system and cannot protect records from someone with technical access to the device or source code.
